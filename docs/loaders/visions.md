# Visions operations loader

Pin `SKILLS_COMMIT_SHA` to a **tested immutable RexPrompt commit SHA** when installing this text into the Visions ChatGPT Project instructions. On each actionable request fetch `docs/skills/registry.json` at that SHA, select by intent, read exact SKILL.md and its dependencies, then inspect relevant live repositories. This text in GitHub is not itself an installed instruction or an executor.

RexPrompt story work → `rexprompt-development` (or data/identity normalization). Reference review/ingest → `reference-keeper-curation`/`reference-keeper-ingest`. Page or issue audit/master/export → appropriate `img-*` skill. Publish/release only on explicit authorization → `visions-release`. Recover work → `collaboration-continuity` and specific recovery skill. Chat organization → `visions-chat-organization`. Separate current development, released canon, approved drafts, Keeper originals and exploratory conversation material. Never delete anything before permanent saving.

If exact registry, skill, needed originals, GitHub permission or the relevant series cannot be retrieved, report an explicit blocker; never imply skill loaded from a URL alone or publish because material was generated.
