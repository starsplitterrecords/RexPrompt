# Universal IMG loader template

Every IMG project uses the SAME procedure as `docs/loaders/series/rex-fleet.md`; only name, relevant live shows.json selectors and same-series visual identity differ. Do not add an alternate approval state, source authority or project cursor. Copy the appropriate audited series loader, set `SKILLS_COMMIT_SHA` to a validated SHA **in the ChatGPT Project instructions**, and test a fresh chat's actual registry/skill retrieval and image readback before cutover. A saved GitHub loader file does not mean Project settings were updated.
