# Comic page master standard

For ordinary interior portrait comics the documented target is **2400 × 3840 pixels**, **5:8**, **sRGB**, **lossless PNG** master. Verify any distinct live cover/spread/print specification separately. Check source image decode, native detail, lettering safety, physical print PPI, aspect and color. Pixel upscaling is not restoration or true regeneration. Never mutate approved source image bytes merely to satisfy export geometry.
