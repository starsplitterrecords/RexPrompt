# Rex Fleet Academy — shared curriculum doctrine

This directory is **development authority shared by the Rex Fleet Academy topic line**. It is not a show and must not be registered as a production series.

The Academy line is organized around **transfer of knowledge**: science, navigation, history, political science, institutions, and lived regional knowledge become stories because instructors and cadets must test what sources claim against apparatus, evidence, simulations, reconstructions, field work, and consequence.

## Course length and line architecture
Rex Fleet Academy is an **umbrella line of self-contained course comics**, not one serial season.

- Default course length: **1 issue**.
- Allowed short limited-course length: **2 or 3 issues** when the material genuinely needs it.
- Three issues is the expected maximum for one course.
- Every Issue 1 must be a valid entry point to both the subject and the Academy line.
- Legacy six/eight/ten-item plans are topic inventories, not promised issue runs.

Each course keeps its own RexPrompt series ID/package, and may use its own instructor, cadets, settings, recurring props, and visual language. A shared Academy cast is not required.

When a course enters image production, prefer a dedicated IMG/reference project for that course. Shared Academy branding and explicit parent references may cross projects; uncontrolled visual state should not.

For Git workflow, use course-specific feature branches while actively developing a course and merge approved work to `main`. Do not use long-lived branches as competing canon.

## Source-text pages
Primary-source or technical text may run across comic pages as a distinct caption track while the visual/classroom story demonstrates and interrogates it. The current pacing experiment begins around **6–9 short source-text lines per page**, normally as separate caption boxes or deliberately grouped units. This is not a quota.

The document voice is not the teacher's dialogue. Instructors should demonstrate, contextualize, challenge, analogize, or apply the source—not simply read it aloud.

Before verbatim adaptation, reconcile authority and edition. Development material must not be promoted to settled canon merely because it reads well.

See `curriculum_doctrine.json` for the complete cross-line contract.
