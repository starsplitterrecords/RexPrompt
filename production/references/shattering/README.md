# Shattering visual references

No approved canonical or current-production image reference is stored in this directory at this checkpoint.

`recovery-binary-note.md` contains provenance for historical image-generation candidates only. Those candidates are not approved drafts and must not be used as visual continuity authority until their original pixels are recovered, inspected, mapped to an exact active page recipe, and approved.

The active production package is page-based. source-scene IDs in recovery records must be translated through `data/shows/shattering/README.md` and then resolved to one exact page by pixel inspection.

Until an image is approved:

- do not add it to `production/drafts/manifest.json`;
- do not treat filenames or scene-level metadata as visual canon;
- do not use regenerated substitutes as recovered references.

The production frontier remains `SHAT_I01_P01` until an approved page image is durably registered.
