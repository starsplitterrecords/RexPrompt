# A2 — Portfolio canonical visual-reference recovery evidence

**Scope:** All 126 RexPrompt registered show/cover units, resolved to 24 source-family packages and their reference shelves, the current 8 published StarSplitterVisions series records, existing curated reference packs, and the accessible File Library image inventory. This is a forensic recovery report, NOT a change of visual approval authority.

**Repository evidence checked:** RexPrompt main Keeper manifest (41 entries after Vikings/Backyard merges); RexPrompt draft manifest; RexPrompt production reference tree; StarSplitterVisions main published pages/covers; the 24 exact source-family subject inventories in \`series-index/\`. The File Library image inventory traversal exhausted its pagination: **3,534 image records in 18 pages**, including many unrelated/alternative images. Indexed Library records do not establish chat approval, completeness of chat history, or permission to promote images.

## Authority and storage

1. Released StarSplitterVisions pages remain the controlling released visual canon at their exact source repository paths.
2. Clearly approved current-production study images may supply scoped corrective or post-release authority only where explicitly intended. Publication and an image's newer date are not interchangeable with approval.
3. RexPrompt Reference Keeper stores copies of image binaries only. The Keeper manifest does not itself grant creative approval or feed pixels to the assembler.
4. For Division Threshold, correctly named IMG Project Source character PNGs remain the independent approved primary production record; low-res Keeper JPEGs are secondary.
5. For Shattering, the source recovery inventory status is \`reference-gate-open-no-approved-images\`; historical generations cannot be made canonical from their titles.
6. Reject thumbnail substitutions for originals, image regeneration, speculative identification from filenames, silent supersession, and edits to released canon.

### Retrieval limits versus absence

Full indexed **Library image catalog** was traversed, but IMG chat histories are not exposed as an exhaustive approval-record API here, and this Project's attached files are mainly production instruction texts, not original images from every IMG project. Some image_file pixel previews work without authorizing raw file bytes. The raw-file materialization attempt for five identified originals (Dominion study, Division Ostra original, Stardust Astra original, Low Tide Matt original, Backyard Sylvie original) returned: *This Project file does not have an authorized raw-byte materialization path.* Noola did materialize successfully and has matching Keeper bytes. **These five are inaccessible as raw originals through the active bridge, not absent or corrupt.**

The accessible sources were not enough to confirm every historical creative approval. No unapproved Library image has been promoted by this report. The four explicitly released image copies above are the only new binary Keeper registrations of this phase.
